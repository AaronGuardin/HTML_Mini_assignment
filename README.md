## How to Run Locally

You do not need to install any heavy tools or servers to run this project. Follow these simple steps:

1. **Download the project** or clone the repository:
   ```bash
   https://github.com/AaronGuardin/HTML_Mini_assignment.git
   ```
2. Navigate into the project folder.
3. Locate the `index.html` file.
4. **Double-click `index.html`** to open it instantly in any modern web browser (Google Chrome, Firefox, Safari, Edge).

### Alternative (Recommended for Development)

If you are using **Visual Studio Code**, install the **Live Server** extension. Right-click on `index.html` and select **"Open with Live Server"** to view changes automatically as you save your code.
